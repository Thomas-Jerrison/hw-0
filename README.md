I created this file in April 2026 while preparing for a MicroMasters capstone exam. On September 13, 2026, I discovered it was empty, so I added this note and repurposed the repository.

This repository adds custom quotes to a single-page Cornell Note PDF and duplicates it into a printable multi-page notebook.

* cornell.pdf: Source template from (https://printsheet.io/cornell/)
* Quote in PDF.py: Overlays custom quotes onto the PDF.
* Page Repetition.py: Duplicates a single-page PDF into a multi-page document.
